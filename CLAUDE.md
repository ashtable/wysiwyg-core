## Project

wysiwyg-core is a Rust library (not a binary). It uses Rust edition 2024.

## Build Commands

- **Build:** `cargo build`
- **Test all:** `cargo test`
- **Test single:** `cargo test <test_name>`
- **Check (fast compile check):** `cargo check`
- **Lint:** `cargo clippy`
- **Format:** `cargo fmt`
